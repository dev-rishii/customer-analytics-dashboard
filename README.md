# Customer Analytics Dashboard

## 📖 Overview
This project analyzes customer behavior during shopping to identify patterns, trends, and insights. It focuses on understanding how customers interact with products and make purchasing decisions.

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy)
- SQL
- Power BI

## 🔍 Key Steps
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data querying using SQL
- Dashboard creation in Power BI

## 📊 Output
An interactive Power BI dashboard that visualizes customer behavior and key trends.
